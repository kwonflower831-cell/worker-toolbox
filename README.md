# 💼 직장인 필수 계산기

2026년 기준 **연봉 실수령액 · 퇴직금 · 시급/주휴수당/최저임금** 계산기. 로그인 없이 무료이며, 모든 계산은 브라우저에서만 이루어집니다(서버 전송 없음).

**👉 [바로 사용하기](https://kwonflower831-cell.github.io/worker-toolbox/)**

## 기능
- 💰 **연봉 실수령액:** 4대보험 + 소득세/지방소득세 공제 내역을 막대 그래프로 확인, 실수령 시급·분당 수입 제공
- 🧾 **퇴직금:** 평균임금 방식, 상여금·연차수당 반영, 1년 미만 안내
- ⏰ **시급·주휴수당:** 월급 환산과 2026년 최저시급(10,320원) 충족 여부
- 📤 결과 공유/복사, 다크모드, 모바일 대응

## 기준 (2026년)
| 항목 | 값 |
|---|---|
| 국민연금 (근로자) | 4.75% (기준소득월액 41만~659만 원) |
| 건강보험 (근로자) | 3.595% |
| 장기요양 | 건강보험료의 13.14% |
| 고용보험 (근로자) | 0.9% |
| 최저시급 | 10,320원 (월 209시간 환산 2,156,880원) |

요율은 [`app.js`](app.js) 상단의 `RATE` 상수만 수정하면 갱신됩니다.

> ⚠️ 소득세는 간이세액표가 아닌 세법 공식 기반 **추정치**입니다. 실제 급여와 차이가 있을 수 있습니다.

## 로컬 실행
빌드 없이 `index.html`을 브라우저로 열면 됩니다. (순수 HTML/CSS/JS)

## 기여
요율 변경, 계산 오류, 새 계산기 제안은 Issue/PR로 환영합니다.
